## Общее описание

Жилой дом, в котором живёт семья Вернеров

## Комнаты

| Комната                | Описание                                                                                                                                                  |
| ---------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Прихожая               | Стандартная прихожая с придверным ковриком, шкафом для вещей и вешалкой, а также небольшой картиной                                                       |
| Комната Вульхабенда    | Среднего размера комната с односпальной кроватью, шкафом, рабочим столом, креслом и скрипкой                                                              |
| Комната Герты и Айнера | Большая комната с двуспальной кроватью, комодом, двумя прикроватными тумбами, большой картиной над кроватью и двумя коврами по сторонам от кровати        |
| Кухня                  | Стандартная кухня с плитой, духовкой, микроволновкой, посудомойкой кофемашиной, чайником, кухонной утварью, обеденным столом и стульями                   |
| Санузел                | Комната, совмещающая туалет, душ и ванную, помимо этого там есть раковина с шкафчиком и зеркалом, стиральная машина, сушильная машина и корзина для белья |
| Кабинет                | Небольшой кабинет с рабочим столом, креслом, компьютером, полками с книгами и несколькими картинами на одной из стен                                      |
| Гостиная               | Относительно большая комната с большим диваном, кофейным столиком, комодом с телевизором и большой картиной, на которой изображены Герта и Айнер          |
| Чердак                 | Комната, вход в которую расположен в одном из коридоров, на нём находится много старых вещей, а также коллекция картин Айнера                             |
