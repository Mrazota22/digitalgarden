## Общее описание

Местная школа Меншенштадта, в которой учатся Вульхабенд, Джереми, Алиса и Малькольм.

## Комнаты

| Комната           | Описание                                                                                                                                                                     |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Общие классы      | Стандартные кабинеты, которые не предназначены для преподавания определённых школьных предметов, на вид слегка бедноваты                                                     |
| Предметные классы | Кабинеты, заточенные под один или два школьных предмета (Иностранный язык, Физическая культура, Математика, Информатика / Родной язык и Литература, Химия и Биология и т.д.) |
| Столовая          | Относительно небольшое помещение, в котором ученики могут перекусить                                                                                                         |
| Кладовка          | Служебное помещение, которое практически не используется, и в которое практически никто никогда не заходит                                                                   |
